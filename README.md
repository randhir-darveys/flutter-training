# Flutter Mini Projects 🚀

This repository contains multiple Flutter mini projects built while learning Dart and Flutter from basics to intermediate concepts.

The goal of this repository is to practice Flutter development through hands-on mini projects covering UI design, state management, API integration, local storage, and database CRUD operations.

## 📦 Package Installation Commands

Install required Flutter packages:

```bash
flutter pub add provider
flutter pub add http
flutter pub add shared_preferences
flutter pub add hive
flutter pub add hive_flutter
flutter pub add sqflite
flutter pub add path
flutter pub add lottie
```

Or install all dependencies:

```bash
flutter pub get
```

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/randhir-darveys/flutter-training.git
```

### 2. Move to Project Folder

```bash
cd flutter-training
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run Project

```bash
flutter run
```

### 5. Build APK (Optional)

```bash
flutter build apk
```
