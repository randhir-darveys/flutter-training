# Flutter Mini Projects

This repository contains multiple Flutter mini projects for learning Dart and Flutter basics.

## Projects

1. FizzBuzz with User Input
2. Bank Account System using OOP
3. Mock JSON Filter and Sort
4. Hello World App with Custom Theme
5. Profile Card UI with Responsive Layout
6. Login and Signup Flow with Form Validation

## Concepts Covered

- Flutter project structure
- Navigation
- StatefulWidget and StatelessWidget
- TextField and Form validation
- OOP concepts in Dart
- Mock JSON data
- Filter and sorting
- Responsive UI using MediaQuery
