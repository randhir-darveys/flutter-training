# Flutter Mini Projects 🚀

A collection of Flutter mini projects built while learning Dart and Flutter concepts step by step.

This repository covers Flutter fundamentals, state management, API integration, local storage, and UI development.

---

## Tech Stack

- Flutter
- Dart
- Provider
- HTTP Package
- SharedPreferences

---
